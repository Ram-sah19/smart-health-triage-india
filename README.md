# Smart Health & Supply Chain Resilience System (India)

An AI-powered public health triage and supply chain resilience platform built for India's healthcare network.

## Key Features
- **Predictive Disease Engine**: 95.00% accuracy NLP classifier trained on symptom data.
- **Supply & Infrastructure Monitoring**: Tracks local hospital bed capacity and emergency medical shipments.
- **Google AI Gemini Integration**: Generates localized, actionable triage reports for ASHA workers in regional languages (Tamil, Hindi, etc.).

## How to Run Locally
1. Clone this repository.
2. Install dependencies: `pip install -r requirements.txt`
3. Run the application: `streamlit run app.py`
